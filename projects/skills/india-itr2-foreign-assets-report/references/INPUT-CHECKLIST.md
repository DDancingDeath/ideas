# Input checklist

## Required for every run

- [ ] Assessment year and financial year
- [ ] Taxpayer name
- [ ] Tax-report directory
- [ ] Residential status
- [ ] Full-return or foreign-schedules-only scope
- [ ] AIS PDF
- [ ] AIS PDF password
- [ ] Form 16 Part A PDF
- [ ] Form 16 Part B PDF
- [ ] Form 12BA/annexure PDF
- [ ] Common Form 16 password, normally PAN in uppercase
- [ ] Prior-year filed ITR JSON/PDF or Schedule FA pages

## Fidelity / foreign shares

- [ ] Calendar-year Fidelity year-end account summary
- [ ] Fidelity transaction summary for the calendar year
- [ ] Fidelity January report
- [ ] Fidelity February report
- [ ] Fidelity March report
- [ ] Form 1042-S or equivalent annual US withholding statement, if issued
- [ ] Open-lots CSV in USD
- [ ] Closed-lots CSV in USD
- [ ] Fidelity account number
- [ ] Actual Fidelity account-opening date
- [ ] ESPP discount percentage
- [ ] Confirmation that ESPP discount was included as salary perquisite
- [ ] RSU/ESPP vest or purchase FMV evidence, if available
- [ ] Historical SBI TT-rate or market-price evidence, if the taxpayer already has it
- [ ] Foreign TIN, or confirmation that passport number will be used
- [ ] Details of any foreign assets outside Fidelity

## Additional files for full ITR-2

- [ ] TIS
- [ ] Form 26AS
- [ ] Bank savings-interest records
- [ ] Fixed/term-deposit interest records
- [ ] Mutual-fund/equity capital-gains statement
- [ ] Tax challans
- [ ] Rent/HRA information
- [ ] Home-loan certificate
- [ ] Old-regime deduction evidence
- [ ] Any house-property, crypto, unlisted-share or other income records

## Intake completion rule

Do not mark intake complete until:

1. The reporting periods are known.
2. Fidelity coverage reaches 31 March for financial-year dividends.
3. Both open and closed lot files have confirmed currency.
4. Prior-year Schedule FA is supplied or explicitly unavailable.
5. Missing information is recorded in the assumptions file.
6. ROR status or schedule applicability has been confirmed.
